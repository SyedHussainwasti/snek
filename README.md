# 🐍 Snake

The classic Snake — eat apples, grow longer, don't crash.

## How to play

Steer the snake to the red apples. Each apple grows you one segment and speeds you up a little. Hitting a wall or your own tail ends the game. Your best score is saved.

## Controls

- **Arrow keys** or **WASD** — steer
- **Swipe** on touch screens — steer
- **Space** — pause / start

Open `index.html` in any modern browser. No build step, no dependencies.

## Files

- `index.html` — the page markup (title, score row, game board, menu overlay)
- `styles.css` — all the styling (colors, layout, overlay, button)
- `app.js` — the game: rules (movement, collisions, scoring) plus drawing and controls, with plain-English comments
